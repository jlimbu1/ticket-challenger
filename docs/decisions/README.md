# Decision records

Architecture Decision Records for significant decisions only —
things with real trade-offs or lasting consequences.

## Format

Files: `NNNN-kebab-case-title.md`, numbered sequentially.

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by [NNNN]

## Context

<!-- Problem, constraints, options considered -->

## Decision

<!-- What we chose and why -->

## Consequences

<!-- Good and bad, follow-ups -->
```

One decision per file. Don't record obvious choices.
